# Milo web interface

This shell carries forward the identity in `ed9c4bf:web/src/styles.css` and
`ed9c4bf:web/src/assets/milo-mark.svg`. The product plan changes the default
interaction to text and the user's screen reader; it does not require a new brand.

- Navy text (`#172c3c`), warm ivory canvas (`#f8f4eb`), near-white input surfaces
  (`#fffdf8`), and restrained amber (`#f0bb58`).
- Segoe UI/system sans-serif, as in the existing application; large body text,
  generous line height and a narrow reading measure.
- One clear reading order: purpose and preview status, request, response, help.
- Standard HTML controls, generous targets and visible high-contrast focus.
- Responsive single-column flow without fixed-height panels or internal scrolling.
- No motion, decorative imagery, external fonts, or voice playback in WEB-1.
- Keep keyboard access, forced colours and text enlargement usable. The mark is
  decorative beside the visible wordmark, never a second screen-reader label.

Mode: operate. The testable purpose is entering a request, understanding why the
preview cannot calculate it yet, and keeping the draft available for editing.
